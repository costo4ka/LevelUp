# LevelUp

Локальное десктопное приложение для формирования привычек. Каждая привычка относится к одной из четырёх категорий, а каждая отметка делает вашего героя сильнее: открываются предметы в комнате и новая одежда, меняется причёска. Один процесс, PyQt6 + SQLite, без сервера, регистрации и сети.

## Запуск из исходников

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt      # Windows: .venv\Scripts\pip ...
.venv/bin/python -m levelup                    # или: python run.py
```

Linux (X11): нужна библиотека `sudo apt install libxcb-cursor0`. Приложение само выбирает платформу `xcb`, потому что под Wayland окна не могут задавать позицию и держаться «поверх всех». Нужен Python 3.12+.

**Посмотреть сразу с историей**, не дожидаясь дней (папка тестовая, настоящие данные не затрагиваются):

```bash
.venv/bin/python tools/make_demo.py /tmp/levelup-demo --base w --days 8      # 8 прошедших дней по привычке в каждой категории
LEVELUP_DATA_DIR=/tmp/levelup-demo .venv/bin/python -m levelup
```

`--days 3` открывает первые предметы, `--days 15` все 12, `--days 25` и больше дают пятую стадию. `--base m|w` выбирает героя, `--habits sport,work` оставляет не все категории. Удалите папку, чтобы начать заново.

## Как это работает

- **Категории**: Спорт, Работа, Учёба, Отношения. Категория выбирается при создании привычки и потом не меняется.
- **Отметка** даёт 10 общих очков и 1 очко своей категории. Повторная отметка в тот же день ничего не добавляет.
- **Предметы**: за 3, 7 и 15 очков категории открывается по предмету. Категории развиваются независимо: можно быть в деловом костюме, но с пустой полкой для книг.

| | 3 очка | 7 очков | 15 очков |
|---|---|---|---|
| Спорт | гантели в комнате | кроссовки и спортивная повязка | штанга на стойке и медаль |
| Работа | стол с ноутбуком | рубашка и пиджак | галстук, классические брюки, туфли, портфель |
| Учёба | стопка книг | очки | книжный шкаф |
| Отношения | фото в рамке | комнатное растение | торшер, гирлянда, ковёр и тёплый свет |

- **Стадии** по общим очкам: 0 «Старт» → 100 «Разгон» → 300 «В ритме» → 600 «Уверенный» → 1000 «Лучшая версия». Они меняют причёску; на пятой стадии вокруг героя появляется свечение.
- **Награда за отметку** (около секунды): герой подпрыгивает, летят звёзды, всплывает «+10» со значком категории, полоски растут. Когда открывается предмет, он появляется со вспышкой и плашкой «Новое: …», новая стадия и закрытый день тоже отмечаются. Все привычки дня выполнены — конфетти и «Все привычки выполнены!».
- **Отмена** сегодняшней отметки возвращает очки, и предмет, открытый этой отметкой, исчезает.

## Как пользоваться

- **Первый запуск**: выбор героя («Он» или «Она»), первая привычка с категорией, часовой пояс. Онбординг считается завершённым только вместе с первой привычкой.
- **Отметка**: клик по строке или `Space` на отметке, в основном окне и в виджете. Окна обновляются только после успешной записи на диск. Повторное нажатие снимает отметку.
- **Главное окно**: слева комната героя, стадия и полоска очков, «ближайшая награда» (что откроется скоро). Справа «Сегодня» со списком и серией, «Развитие» по категориям, календарь «Дни без пропусков» за пять недель.
- **Коллекция** показывает все стадии и все 12 предметов (закрытые серые) и ведёт в «О программе» со списком авторов графики.
- **Виджет**: компактное окно поверх остальных, перетаскивается за верхнюю полосу, позиция запоминается. «Открыть» показывает основное окно, «Скрыть» убирает виджет и возвращает основное окно.
- **Закрытие основного окна**: если виджет виден, окно просто скрывается и виджет работает дальше, иначе приложение завершается. Полный выход: «Выйти» или `Ctrl+Q`.
- **Архивирование**: кнопка «···» (или правая кнопка) на строке. Сегодняшняя отметка снимается, место освобождается, история и очки остаются. `Ctrl+N` — новая привычка.

## Правила

| | |
|---|---|
| Очки | 10 за уникальную отметку «привычка + день»; сумма и очки категорий вычисляются по отметкам (включая архивные привычки), отдельных счётчиков нет |
| Стадии | 5, порог — наибольший достигнутый: 0 / 100 / 300 / 600 / 1000 |
| Предметы | тиры категории 3 / 7 / 15 очков |
| Пропуск дня | очки и образ не уменьшаются; отмена ошибочной сегодняшней отметки может вернуть предыдущую стадию или закрыть предмет |
| Серия | подряд идущие «полные» дни (выполнены все привычки, у которых `start_date ≤ день < archived_date`); день без привычек серию разрывает; если сегодня не выполнено всё — счёт идёт со вчера. Дополнительных очков за полный день нет |
| Лимиты | до 5 активных привычек, до 1000 всего (с архивными), название 1–80 символов, без дублей среди активных |
| Дата | по часовому поясу профиля; смена дня проверяется раз в 30 с, перед каждой командой и при возвращении в окно; откат часов блокирует запись (`CLOCK_ROLLBACK`), просмотр остаётся |

Правила, категории, названия предметов и пороги лежат в `levelup/assets/config.json`, слои героя и предметы комнаты — в `levelup/assets/sprites/character/character.json` и `room/room.json`. Менять их из интерфейса нельзя; `xp_per_completion` для существующей базы менять нельзя (нужна миграция).

## Данные пользователя

| ОС | Каталог |
|---|---|
| Windows | `%LOCALAPPDATA%\LevelUp\` |
| Linux | `~/.local/share/LevelUp/` |

Внутри: `data.db` (SQLite), `backups/` (перед каждой миграцией — копия через SQLite Backup API, хранятся 3 последние), `logs/` (3 файла по 1 МБ, без названий привычек), `levelup.lock` (защита от второго экземпляра).

Версия схемы 2: привычки получили категорию. Привычки из версии 1 при обновлении получают категорию «Спорт» (копия базы делается до миграции).

**Ручное резервное копирование**: закройте приложение («Выйти») и скопируйте `data.db`. Восстановление — положить файл обратно. Удаление каталога сбрасывает все данные; обновление приложения каталог не трогает. Повреждённую базу приложение никогда не заменяет пустой — оно сообщит, где лежат файл и копии. Для разработки каталог можно переопределить переменной `LEVELUP_DATA_DIR`.

## Тесты и инструменты

```bash
.venv/bin/python -m pytest -q
```

Интерфейс проверяется без экрана (`offscreen`). Покрыто: нормализация названий, пороги стадий и тиров категорий, серия и календарь, идемпотентность и отмена, очки по категориям и предметы, события наград, `DATE_CHANGED` и полночь в часовом поясе профиля, откат часов, откат транзакции при сбое диска, блокировка БД, лимиты, миграции (в том числе v1→v2) с копией и откатом, повреждённая БД, конфигурация и манифесты спрайтов, сцена и её анимации, окна, диалоги, онбординг, время отклика на БД с 21 500 отметок.

Инструменты (`tools/`): `make_demo.py` (папка данных с историей), `seed_history.py` (дозаполнить историю в уже созданной тестовой папке), `screenshots.py` (рисует окна и диалоги в PNG без экрана, ищет обрезанный текст), `build_character.py` и `build_room.py` (пересобирают спрайты героя и комнаты, см. ниже), `make_icon.py` (значок приложения).

## Структура

```
levelup/
  domain/          правила, ошибки, часы, снимок состояния и событие награды (без Qt и SQLite)
  application/     service.py — AppService (вся бизнес-логика), worker.py — Qt-worker и контроллер
  infrastructure/  db.py (миграции, копии), repository.py (SQL), paths.py, tz.py, logging_setup.py
  look.py          какие слои героя и предметы комнаты показывать (без Qt)
  ui/              тема, окна, виджет-оверлей, сцена и анимации (scene.py, effects.py), диалоги, онбординг
  assets/          config.json, sprites/ (character, room, icons, fx), fonts/, значок
tests/
tools/
```

Все обращения к SQLite идут в одном отдельном потоке (`QThread`), интерфейс не блокируется. `set_completion` и `archive_habit` выполняются в `BEGIN IMMEDIATE … COMMIT`, дата фиксируется в начале транзакции. Контроллер после записи шлёт `state_changed`, затем `reward` с состоянием до и после — по нему сцена рисует награду.

## Сборка для Windows 10/11 x64

На Windows с Python 3.12 x64 запустите `build_windows.bat`: он ставит зафиксированные зависимости, гоняет тесты и собирает PyInstaller onedir без UPX в `dist\LevelUp-windows-x64.zip`. Распакуйте архив и запустите `LevelUp.exe` — Python и права администратора не нужны.

Спецификация сборки проверена пробной сборкой на Linux (версия 2: запускается, ассеты и tzdata внутри). На самой Windows сборка и запуск на чистой машине **не проверялись**, как и ручные пункты приёмки: «поверх окон» в Windows, DPI 100/125/150 % (пиксельная сцена масштабируется целым множителем, при дробном масштабе экрана возможны неровные пиксели), отключение монитора.

## Готовые сборки

Windows x64 и Linux x64 собирает GitHub Actions ([.github/workflows/build.yml](.github/workflows/build.yml)): тесты, PyInstaller onedir, проверка запуска. Архивы каждой сборки на `main` лежат в артефактах запуска (вкладка Actions), а релиз с готовыми архивами и контрольными суммами создаётся при пуше тега вида `v1.0.0` (вкладка Releases). Для Linux нужна библиотека `libxcb-cursor0`; исполняемый файл Windows не подписан, поэтому SmartScreen может показать предупреждение.

## Решения, отличающиеся от ТЗ

- **Категории и предметы** добавлены к модели ТЗ (привычка получила категорию; очки категории открывают предметы).
- **«Спорт» меняет экипировку и предметы, а не телосложение**: у мускулистого тела в наборе LPC нет рубашек и пиджаков, и комбинация «спортсмен в костюме» была бы невозможна.
- **Выбор героя** («Он» / «Она») добавлен в онбординг и в `finish_onboarding(base_id)`.
- В снимок добавлены поля `base_id`, `onboarding_done`, `clock_rollback`, `max_active_habits`, `stage_count`, `stage_name`, `categories`, `unlocked`, `day_complete`, `full_days`.
- Для `DATE_CHANGED` ответ содержит только ошибку (по правилу «ровно одно из data и error»); новый снимок интерфейс запрашивает сам.

Не реализовано по ТЗ: премиум, дополнительные стили, графики, социальные функции, облако, системные уведомления, автозапуск, редактор персонажа.
